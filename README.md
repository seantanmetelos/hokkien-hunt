# Hokkien Hunt

Mobile-first Singapore fried Hokkien prawn mee discovery app.

## Features
- 20 publicly listed stalls (locations approximate; not field verified)
- Interactive map and search
- Approximate travel-time recommendations
- Saved/visited passport stored locally on the device
- Installable PWA

## Cloudflare Pages deployment
Create a **new Git-integrated Cloudflare Pages project** from this repository. Select branch `main`, framework preset **None**, leave the build command empty, and use `/` or `.` for the build output directory (repository root).

The existing direct-upload Pages project cannot be converted directly to Git integration. Keep it until the replacement is tested.

## Limitations
No direct Google/Outlook calendar sync, no live opening hours, queue times or travel routes. Check stall details before visiting.
